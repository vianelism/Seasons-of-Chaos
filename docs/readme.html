PROJECT GUIDE

Seasons of Chaos

A playful, year-round seasonal passport app for a Discord community. Every stamp stacks into one lifetime passport, while members can filter their collection by Fall, Winter, Spring, or Summer.

Live architecture

Discord slash command
  → Cloudflare Worker (signed HTTP interaction)
  → Cloudflare D1 (users, stamps, earned stamps)
  → Discord embed or confirmation

No always-running computer, gateway connection, Railway service, or Supabase project is required.

Commands

  • /passport [user] — view an embed passport, earned stamps, progress, and locked achievements
  • /passport [user] [season] — optionally filter the lifetime passport by season
  • /stamps [season] — browse active public stamps without exposing secret achievements
  • /seasons — browse current, upcoming, and archived seasonal collections
  • /rewards [user] — view seasonal and lifetime reward progress
  • /event-guide — show what is next on the live September–January schedule
  • /emotes [name] — browse uploaded community emotes or post one in the channel
  • /add-emote name — moderator-only copy of an application emote into the server picker
  • /award user stamp [announce] — moderator-only award with duplicate prevention
  • /revoke user stamp — moderator-only correction
  • /setup-channel kind channel — choose scheduled-activity and participation-tracking channels
  • /automation-status — show which channels are being watched
  • /check-in activity — self-service activity stamp with no moderator approval
  • /setup-rewards — create, connect, and synchronize Fall reward roles
  • /chaos-help — show a short member-friendly guide

Administrators and members with Manage Server can use moderator commands. Additional moderator role IDs can be configured in wrangler.jsonc.

Community emotes

The bot discovers custom emojis from the Discord application and presents them as community emotes. Run /emotes to browse a clean five-group drawer or post one. Moderators can run /add-emote name: to copy a selected emote into the server's normal picker for inline use. The bot needs Create Expressions permission and an open emote slot. Bot messages use emotes in relevant passport, award, reward, tracking, and help moments—not as random unsolicited posts.

Fall Into Chaos 2026–27

The original September–January event is the first Seasons of Chaos cycle. Fall 2026 contains September's Cozy Fall Kickoff, October's Halloween Chaos, and November's Discord Friendsgiving; Winter 2026–27 carries December's Holiday Chaos and January's We Survived wrap-up. The passport continues across both collections without resetting.

Select Scheduled activities and prompts once with /setup-channel. The hourly Worker then runs a 66-post schedule from September 1 through January 27: September kickoff activities, all 31 Days of Halloween, Friendsgiving, 12 Days of Discord, holiday check-ins, and January's wrap-up. D1 prevents duplicate posts, and /event-guide derives its upcoming list from that same schedule rather than a manually maintained summary.

Halloween movie night, holiday movie night, and January game night use two-stage native Discord polls. Members select every workable date, the bot follows with a time poll, and then it summarizes the leading option while preserving ties and an asynchronous/cannot-attend-live choice. Everything remains free and optional, with no purchases or leaderboards.

Automatic Fall 2026 tracking

The Worker posts due activities and checks configured participation channels once per hour. A single Discord channel may be selected for more than one type.

  • Scheduled activities and prompts runs the complete September–January hosting calendar.
  • Seasonal conversation awards monthly participation stamps.
  • Photo sharing awards “Pics or It Didn't Happen” when a message contains an attachment.
  • Movie-night and game-night activity awards their event stamps.
  • Activity on several different days unlocks rule-based secret achievements.
  • Participating across September, October, and November unlocks “I Was Here.”
  • /check-in handles activities the bot cannot infer reliably, such as a costume, seasonal treat, or gratitude post.
  • Reward thresholds are evaluated immediately after every automatic or self-service award.

The bot needs View Channel, Read Message History, and Send Messages in configured channels. Reward roles also require Manage Roles.

The Discord application's Interactions Endpoint URL must be the production Worker URL.

Local setup

Requirements: Node.js 20+, an authenticated Cloudflare account, and a Discord application.

npm install
cp .env.example .env
npm run db:migrate:local
npm run dev

Enter the Discord development values in .env. Never commit that file. Normal Discord testing should use the deployed Worker because Discord cannot reach localhost directly.

Deploy changes

npm run check
npm run deploy

After adding a migration:

npm run db:migrate:remote
npm run deploy

After changing slash-command definitions:

npm run deploy:commands

After changing wrangler.jsonc:

npx wrangler types worker-configuration.d.ts
npx wrangler types --check

Stamp catalog

The initial catalog lives in migrations/0001_initial.sql. Seasons, stamp mappings, and rewards are introduced in migrations/0002_seasons_and_rewards.sql. The catalog in src/config/stamps.ts remains a readable source list, but D1 is authoritative at runtime.

Stamps without a stamp_seasons mapping are lifetime-global. Seasonal stamps can be filtered in /passport without changing or resetting lifetime award history.

For future changes, create a new numbered migration instead of editing one that has already run:

npx wrangler d1 migrations create DB add-new-stamps

Use a stable slug for every stamp. Changing a slug creates a different achievement and can disconnect existing award history.

Secrets and verification

npx wrangler secret put DISCORD_PUBLIC_KEY

Do not place secrets in wrangler.jsonc, source files, or GitHub. The production Worker uses the bot token to scan configured channels and announce automatic awards.

curl https://seasons-of-chaos.v-martinez1.workers.dev
npx wrangler d1 execute DB --remote --command "SELECT COUNT(*) FROM stamps"
npx wrangler secret list
npx wrangler tail seasons-of-chaos

Cloudflare observability is enabled with structured error logging. D1 enforces unique guild/user/stamp awards, preventing duplicate awards even across simultaneous requests.
